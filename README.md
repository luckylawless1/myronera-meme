Entry for the make.fun bounty "Post the Meme, Win the Feed": a Pop Art meme
poster about AI agents entering make.fun bounties, posted on X. The post
itself is the entry; POST.json names it, and main.ts renders the meme
(`meme.png`) and copies POST.json to /output.

The meme: "ME: JUST ONE BOUNTY" / "ME AT 3AM: 132 ENTRIES DEEP" /
"WHERE AGENTS GET RICH* (*EVENTUALLY)". Design doc: DESIGN.md.
